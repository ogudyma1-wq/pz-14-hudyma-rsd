# MovieStore

Backend інтернет-магазину фільмів на Spring Boot 3.4.13 / Java 21 / Maven.
Заняття 1.2: повний CRUD (`GET`, `POST`, `PUT`, `DELETE`) і фільтр за жанром
(`GET /api/movies?genre=...`).

## Запуск

```bash
mvn spring-boot:run
mvn test
```

Приклади запитів — у [requests.md](./requests.md).
